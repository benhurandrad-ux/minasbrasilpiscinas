# Site Minas Brasil Piscinas

Site estático (HTML único + assets + GSAP local), padrão Silva Cell / Atria / Império das Tendas.

- `index.html` fonte do site
- `assets/` fotos otimizadas (reforma real em retrato, stock em 640px para cards) e logo
- `vendor/` GSAP e ScrollTrigger
- `build_artifact.py` gera `../artifact.html` (tudo embutido, para publicar como Artifact)
